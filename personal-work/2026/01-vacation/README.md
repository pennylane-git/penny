# 2026 Summer Vacation Plan

Mobile-first static vacation calendar for a public-but-unlisted GitHub Pages link.

## Privacy Notes

- The page includes `noindex` and `nofollow` meta tags.
- `robots.txt` disallows crawling.
- Reservation numbers, member numbers, and personal names are intentionally omitted from `index.html`.
- GitHub Pages is still a public URL. Anyone with the link can open it.

## To Publish With GitHub Pages

1. Create a repository on GitHub.
2. Push this folder to the repository's `main` branch.
3. In GitHub, open `Settings > Pages`.
4. Choose `Deploy from a branch`, branch `main`, folder `/root`.
5. Save and wait for the Pages URL.
